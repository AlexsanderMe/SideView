# Security policy

## Supported versions

Until SideView reaches `1.0.0`, security fixes are provided for the latest
published minor version. Older pre-release lines are not maintained.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue or pull request.
Use GitHub's
[private vulnerability reporting](https://github.com/AlexsanderMe/SideView/security/advisories/new)
to share the impact, affected versions, reproduction steps, and any suggested
mitigation.

You should receive an acknowledgement within three business days and an initial
assessment within seven business days. Timelines for a fix and coordinated
disclosure depend on severity and complexity.

Reports about vulnerabilities in WebView2, WKWebView, WebKitGTK, Qt, or PySide6
may need to be coordinated with the corresponding upstream project. SideView
will still assess whether a local mitigation is appropriate.
